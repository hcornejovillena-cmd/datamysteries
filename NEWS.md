# datamysteries 0.1.0

Primera version piloto academica para compartir con docentes.

- Incluye el Caso 1: "La caida de Lucahura".
- Agrega vignettes bilingues para estudiantes.
- Agrega solucion docente fuera del paquete instalado.
- Agrega datos reproducibles desde `data-raw/case1_lucahura.R`.
- Agrega tests estructurales y pedagogicos con `testthat`.
- Agrega verificacion automatica con GitHub Actions.
- Agrega guia de contribucion y plantillas para nuevos casos.
